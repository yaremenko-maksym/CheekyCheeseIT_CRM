## Ревью владельца 2026-06-23 (вердикт — приоритет над генерацией CD)

Владелец посмотрел content-only генерацию (с телефона) — **направление одобрено** («выглядит солидно»),
с правками. Вердикт приоритетнее любого CD-вывода:

1. **Цвета колонок — СОХРАНИТЬ** (помогают ориентации; команда привыкает со временем). НЕ нейтрализуем
   в монохром. См. §«Цвет стадий».
2. **Убрать теги и оценки полностью** — в модели их нет (CD-выдумка), не рисовать.
3. **Аватар HR → ссылка на профиль** (`/profile/$hrId`); сейчас `hrName` — просто текст.
4. **Ссылка на звонок (`callUrl`) — явно кликабельная** в зоне напоминания (не только мелкая иконка).
5. **Новая логика собеседований** (отдельная фича — см. «Связанный рефактор»): сброс `callUrl` при
   переносе стадии; предупреждение «встреча не назначена» → дозаполнить дату/время + ссылку на звонок
   (Meet/Teams) ЛИБО мессенджер-контакт (Telegram/телефон); напоминание «состоялось N дней назад».
6. **Будущее (заглушки-disabled):** списочный вид; календарный вид + интеграция Google Calendar.

- **Заголовок:** лейбл стадии + **счётчик** карточек (badge). Текущее: цветной фон/текст per stage.
- **Список карточек** (drop-zone, dnd-kit sortable). Пустая колонка — пустое тело.

### D. Карточка (`InterviewCard` / `InterviewCardStatic`)

Реальная модель (`InterviewDto`): `companyName · vacancyUrl · callUrl · hrId/hrName · createdAt · stage`.
**Поля «кандидат» НЕТ** (аутстафф: синьор и есть кандидат) — не выдумывать. Элементы карточки:

- **Компания** (`companyName`, bold, truncate).
- **Ссылка на вакансию** (`vacancyUrl` → иконка `ExternalLink`, clickable, `stopPropagation`).
- **Ссылка на звонок** (`callUrl` → clickable, `stopPropagation`) — вердикт: **явно кликабельная** в зоне напоминания (не только мелкая иконка).
- **HR** (`hrName`/`hrId`) → вердикт: **аватар HR со ссылкой на профиль** `/profile/$hrId` (сейчас просто текст — заменить на avatar-link).
- **Дата** (`createdAt`, `formatDate`).
- Draggable; клик по карточке → detail-sheet.
- **НЕ добавлять:** теги, оценки, имя кандидата (нет в модели — CD-выдумка).

## Design direction (рестайл по `foundation.md` — на апрув владельцу)

- **Цвет стадий — РЕШЕНО (владелец 2026-06-23): СОХРАНИТЬ семантические цвета колонок.** Довод: цвета помогают ориентироваться, команда привыкает со временем. → НЕ нейтрализуем в монохром. Задача редизайна: привести палитру 9 колонок к нашим токенам / `foundation.md` (гармоничнее, без «кислотности»), сохранив различимость стадий; активные vs терминальные различимы (терминальные приглушённее); бренд-жёлтый остаётся CTA/active-акцентом и не сливается со стадийными цветами.
- Плотность/типографика/отступы — по foundation; счётчики `tabular-nums`.

## A11y / responsive

- **A11y (WCAG 2.2):** keyboard drag (есть KeyboardSensor) — сохранить; focus-видимость на карточках/колонках; счётчики/бейджи контраст; `aria` на drag-ручках/кнопках.
- **Responsive (4 класса, `responsive-design.md`):** мобайл (<640) — доска горизонтальный скролл, колонки читаемой ширины, свайп; управляющая строка wrap; тач-таргеты ≥44px (карточки/кнопки). Планшет/ноут/большой — доска как есть, без overflow страницы (скролл внутри доски, не страницы).
