## Summary

**Create:** 6 skills.

1. `playwright-patterns` (CRM-specific Playwright cookbook).
2. `code-review-discipline` (delta over ECC code-reviewer.md — write-then-post, BLOCK semantics, zone violations).
3. `dev-flow-resilience` (D1-D4 RCA lift — watchdog asymmetry / cross-session loss / zones-of-write).
4. `ua-tax-compliance` (FOP/LLC-Diia City/CFC structural patterns).
5. `ua-crypto-compliance` (Law 2074-IX + AML/Law 361-IX UA snapshot).
6. `ua-it-contract` (IT-contract risks + lawyer engagement prep).
7. `legal-escalation-patterns` (hard refuse + evasion variant patterns).

**Skip:** 3 candidate skills (`nestjs-patterns`, `react-patterns`, `react-testing`) — insufficient substantive content. Reassess in Phase 6+ when more lessons accumulate.
