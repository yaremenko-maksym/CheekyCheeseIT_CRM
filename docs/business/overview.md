# Бизнес-модель Cheeky Cheese IT

## Концепция

**Cheeky Cheese IT** — компания обратного рекрутинга (reverse recruiting).

**Суть модели:** HR находит вакансии на рынке → SENIOR проходит интервью от лица компании → JUNIOR работает вместо него → финансы распределяются между всеми участниками.

## Роли и права доступа

| Роль | Описание | Может создавать | Видит |
|------|----------|-----------------|-------|
| **ADMIN** | Владелец системы | Всё | Все данные всех пользователей |
| **SENIOR** | Проходит интервью, управляет проектом | Транзакции, заметки интервью | Свои проекты, своя доска интервью, свои финансы |
| **JUNIOR** | Работает над проектом | — | Проекты где активный member, базовые данные |
| **HR** | Находит вакансии, ведёт собеседования | Команды, проекты, карточки интервью | Свои команды + связанные синьоры/проекты |
| **ACCOUNTANT** | Финансовый учёт | Расходы, выплаты | Все транзакции всех синьоров |

## Финансовый поток

```
SENIOR получает зарплату от клиента
        ↓
SENIOR вносит транзакцию в систему
  (дата, сумма, валюта, проект, чек)
        ↓
ACCOUNTANT получает уведомление → валидирует транзакцию
        ↓
SENIOR видит статус VALIDATED → нажимает "Оплатить услуги"
        ↓
SENIOR платит 74% на смарт-контракт (Phase 8)
  JUNIOR получает фиксированную сумму первым
  Остаток 50/50 → ADMIN кошелёк + партнёр кошелёк
        ↓
SENIOR оставляет себе 26%
```

## Организационная структура

- Команда = 1 HR + 1-4 SENIOR + соответствующие JUNIOR + 1 ACCOUNTANT (общий на всю компанию)
- ADMIN может создать максимум 10 команд
- JUNIOR может быть в нескольких командах одновременно
- ACCOUNTANT один на всю компанию (автоматически добавляется в каждую команду)

## Жизненный цикл проекта

```
HR/ADMIN создаёт проект → назначает SENIOR
        ↓
SENIOR проходит интервью (канбан-доска) → получает оффер
        ↓
JUNIOR добавляется в проект (ADMIN/HR)
        ↓
SENIOR получает зарплаты → ACCOUNTANT валидирует → финансовый поток
        ↓
SENIOR уходит → проект закрывается (статус CLOSED, архив)
```
