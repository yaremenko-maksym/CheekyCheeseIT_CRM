# Юридические драфты — контракты ролей + пользовательское соглашение

> **AI-черновики.** Сгенерированы legal-агентом как preliminary drafts + прошли независимый ревью-проход. **Не готовы к подписанию** — требуют проверки практикующим IT-corporate / privacy юристом.

## Файлы

| Файл                     | Что                                         | Язык     |
| ------------------------ | ------------------------------------------- | -------- |
| `contract-hr.md`         | HR / рекрутер                               | UA \| EN |
| `contract-accountant.md` | Бухгалтер                                   | UA \| EN |
| `contract-junior.md`     | Джуниор-разработчик                         | UA \| EN |
| `user-agreement-tos.md`  | Пользовательское соглашение платформы (ToS) | RU       |

Все 3 договора — ЦПХ «Договір про надання послуг». Направление сторон: **компания = Замовник (платит)** **ФОП = Виконавець (получает)**. Это контракты для реальных людей, которые работают **под своим именем** (никакой подмены личности).

## Куда вставлять наполнение senior / drop

Шаблоны контрактов живут в таблице **`contract_templates`** — по одному активному на роль (`SENIOR` / `JUNIOR` / `HR` / `ACCOUNTANT` / `DROP`; для `ADMIN` шаблона нет по DB-constraint).

- **UI (рекомендуется):** `/crm/admin/templates/contracts` (список ролей) → выбрать роль → редактор → вставить `body_markdown` → опубликовать.
  Роуты: [contracts.index.tsx](../../../apps/web/app/routes/crm/admin/templates/contracts.index.tsx) · [contracts.$role.tsx](../../../apps/web/app/routes/crm/admin/templates/contracts.$role.tsx)
- **API:** `POST /api/contracts/templates` с `{ targetRole, bodyMarkdown }` (только ADMIN, throttle 5/мин). Каждая публикация создаёт новую версию и деактивирует предыдущую — старые версии сохраняются.

В тексте используй плейсхолдеры (ниже) — подпись и рендеринг подставят значения автоматически, **функционал подписи не меняется**.

## Плейсхолдеры (резолвятся движком при превью/подписи)

Источник: [contract-rendering.ts](../../../apps/api/src/contracts/contract-rendering.ts)

| Токен                                                                | Значение                                                                                               |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `{{employeeName}}`                                                   | юр. ФИО (legalFullName → displayName)                                                                  |
| `{{employeeEmail}}`                                                  | email                                                                                                  |
| `{{role}}`                                                           | роль (HR/Junior/…)                                                                                     |
| `{{onboardingDate}}`                                                 | дата подписания (YYYY-MM-DD)                                                                           |
| `{{companyName}}`                                                    | бренд-имя компании                                                                                     |
| `{{companyLegalName}}` · `{{companyAddress}}` · `{{companyCountry}}` | реквизиты юр-лица из константы [`CONTRACT_COMPANY`](../../../apps/api/src/common/pdf/pdf.constants.ts) |
| `{{walletUsdt}}`                                                     | USDT-кошелёк (ERC-20)                                                                                  |
| `{{bankUahFop}}`                                                     | банк UAH/ФОП (получатель, IBAN, РНОКПП, банк)                                                          |
| `{{preferredMethod}}`                                                | предпочитаемый метод оплаты                                                                            |
| `{{requisites}}`                                                     | умные реквизиты (USDT или банк — по `paymentMethod`)                                                   |

Поля, которых платформа сейчас **не хранит** (рег. адрес и телефон контрагента; рег.№ / VAT / IBAN компании), помечены `[ВПИШИ: …]`. Чтобы автозаполнять и их — нужно добавить плейсхолдеры/поля (отдельный мелкий PR).

## Двуязычие в PDF (важно для встройки)

Драфты — двухколоночные markdown-таблицы (UA | EN). **Текущий PDF-рендер контракта одноколоночный и таблицы не рендерит.** Для настоящих параллельных колонок в подписываемом PDF нужна доработка верстки рендера ([contract-pdf.service.ts](../../../apps/api/src/contracts/contract-pdf.service.ts)) — это отдельная задача; сам флоу подписи не трогается.

## Приоритеты для живого юриста

1. **Переквалификация в трудовые** — независимость ФОП-подрядчиков от работодателя (фикс-оплата + долгосрочность = остаточный риск, особенно у `junior`).
2. **Валютный механизм** оплаты нерезидентом + **USDT на ФОП-3** (риск исключения из единого налога).
3. **Применимое право и форум** — согласовать сразу по всем 4 документам (сейчас ToS берёт право страны компании, договоры оставляют открытым).
4. **Постоянное представительство (PE)** нерезидента в Украине — риск при систематическом найме через UA-резидентов.
