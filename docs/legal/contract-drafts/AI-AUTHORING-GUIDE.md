# Инструкция для ИИ: как сгенерировать контракт в формате платформы

> Скопируй весь этот текст в начало промпта для ИИ, затем добавь снизу описание нужного контракта (роль, предмет, коммерческие условия). ИИ вернёт markdown, который **без переделок** вставляется в платформу и стабильно рендерится в двухколоночный PDF.

## Что нужно на выходе

Один markdown-файл с **двуязычным контрактом**: украинская и английская версии **построчно, в две параллельные колонки**. Колонки делаются markdown-таблицей: левая колонка — українська, правая — English. Каждый пункт договора = одна строка таблицы, где левая и правая ячейки — **один и тот же пункт на двух языках** (смысл должен совпадать дословно).

## Жёсткие правила формата (иначе PDF разломается)

1. **Заголовок документа** — обычным markdown над таблицей: `# НАЗВА ДОГОВОРУ / CONTRACT TITLE` (через `<br>` можно дать обе языковые версии в одну строку).
2. **Каждый раздел = отдельная маленькая таблица** из 3 частей:
   - строка-шапка: `| Українська | English |`
   - строка-разделитель: `| --- | --- |`
   - далее строки-пункты: `| текст пункту UA | clause text EN |`
3. **Ровно 2 колонки** в каждой строке таблицы. Никогда не 1 и не 3.
4. **Заголовок раздела** — жирным внутри ячеек: `| **1. ПРЕДМЕТ ДОГОВОРУ** | **1. SUBJECT** |`.
5. **Жирный текст** — только `**...**`. Никакого `_курсива_`, `~~зачёркивания~~`, HTML, картинок, вложенных таблиц, ссылок-картинок.
6. **Нельзя** использовать символ `|` внутри текста ячейки (он ломает колонки). Если очень нужен — экранируй `\|`.
7. Длинные значения (адреса, IBAN, кошельки) можно вставлять — рендерер сам перенесёт по словам и при необходимости разобьёт длинный токен; ничего за границу колонки не вылезет.
8. Вне таблиц допускается: `#`/`##` заголовки, `- ` списки, `**жирный**`, пустые строки (= абзацный отступ), `> ` цитата (для дисклеймера). Всё это рендерится в одну колонку на всю ширину.

## Плейсхолдеры (НЕ выдумывай новые — только из этого списка)

Подставляются движком автоматически из профиля сотрудника и константы компании при подписи/превью:

| Токен                                                                          | Значение                                              |
| ------------------------------------------------------------------------------ | ----------------------------------------------------- |
| `{{employeeName}}`                                                             | юр. ФИО сотрудника                                    |
| `{{employeeEmail}}`                                                            | email сотрудника                                      |
| `{{role}}`                                                                     | роль (HR / Junior / Accountant …)                     |
| `{{salary}}`                                                                   | ставка сотрудника из формы создания (напр. «800 USD») |
| `{{onboardingDate}}`                                                           | дата подписания                                       |
| `{{companyName}}`                                                              | бренд-имя компании                                    |
| `{{companyLegalName}}` · `{{companyAddress}}` · `{{companyCountry}}`           | реквизиты юр-лица (Замовник/Виконавець-компания)      |
| `{{requisites}}` · `{{bankUahFop}}` · `{{walletUsdt}}` · `{{preferredMethod}}` | платёжные реквизиты сотрудника                        |

- **Ставку всегда вставляй через `{{salary}}`** (она задаётся при создании сотрудника), не пиши сумму руками.
- Реквизиты компании — только через `{{companyLegalName}}/{{companyAddress}}/{{companyCountry}}`, не хардкодь название.
- То, чего нет среди плейсхолдеров и что задаётся вручную (рег. номер, VAT, IBAN компании; рег. адрес/телефон сотрудника; номер договора), помечай ровно так: `[ВПИШИ: что именно]`.

## Стороны (направление задаёшь под конкретную роль)

- Если **компания платит** сотруднику (HR, Junior, Accountant): компания = **Замовник / Customer**, сотрудник = **Виконавець / Contractor (ФОП)**.
- Если **сотрудник платит** компании (% от дохода): сотрудник = **Замовник**, компания = **Виконавець**.
- Тип договора: «Договір про надання послуг» (ЦПХ), а не трудовой.

## Подписи (по одной на каждую сторону, аккуратно)

Последний раздел — реквизиты и подписи, тоже двухколоночной таблицей. По **одной** подписи на сторону:

```
| **РЕКВІЗИТИ ТА ПІДПИСИ СТОРІН** | **DETAILS AND SIGNATURES** |
| --- | --- |
| **ЗАМОВНИК / CUSTOMER:** | **ВИКОНАВЕЦЬ / CONTRACTOR:** |
| {{companyLegalName}} | Фізична особа — підприємець {{employeeName}} |
| {{companyAddress}}, {{companyCountry}} | E-mail: {{employeeEmail}} |
| Реєстраційний номер: [ВПИШИ: рег. номер] | РНОКПП: [ВПИШИ: РНОКПП] |
| | Реквізити: {{requisites}} |
| Підпис / Signature: ______________________ | Підпис / Signature: ______________________ |
```

(Левая колонка — одна сторона, правая — другая; по одной строке подписи в каждой.)

## Рекомендуемый набор разделов (профессиональный стандарт)

1. Преамбула (стороны) · 2. Предмет · 3. Права та обов'язки Виконавця · 4. Права та обов'язки Замовника · 5. Порядок приймання послуг · 6. Ціна та оплата (через `{{salary}}`) · 7. Відповідальність + форс-мажор · 8. Конфіденційність · 9. Інтелектуальна власність · 10. Захист даних (GDPR/ЗУ 2297-VI) · 11. Строк дії та розірвання · 12. Інші умови (мовний пріоритет!) · 13. Застосовне право та спори · 14. Реквізити та підписи.

Обязательно добавь пункт про **мовний пріоритет** (какая версия — UA или EN — главная при расхождении) и шапку «AI-черновик, потребує перевірки юристом» цитатой `>` сверху.

## Минимальный скелет (копируй структуру)

```markdown
> AI-черновик — потребує перевірки юристом / AI draft — requires lawyer review.

# ДОГОВІР ПРО НАДАННЯ ПОСЛУГ № [ВПИШИ: номер]<br>SERVICES AGREEMENT No. [ВПИШИ: number]

**Дата / Date:** {{onboardingDate}}

| Українська                                  | English                                            |
| ------------------------------------------- | -------------------------------------------------- |
| **1. ПРЕДМЕТ ДОГОВОРУ**                     | **1. SUBJECT OF THE AGREEMENT**                    |
| 1.1. Виконавець надає Замовнику послуги ... | 1.1. The Contractor provides the Customer with ... |

| Українська                                                | English                                            |
| --------------------------------------------------------- | -------------------------------------------------- |
| **6. ЦІНА ТА ОПЛАТА**                                     | **6. PRICE AND PAYMENT**                           |
| 6.1. Винагорода Виконавця становить {{salary}} на місяць. | 6.1. The Contractor's fee is {{salary}} per month. |
```

После генерации вставь результат через админ-редактор `/crm/admin/templates/contracts` (см. `README.md`).
