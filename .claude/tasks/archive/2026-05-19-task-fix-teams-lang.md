# task-fix-teams-lang

## Агент: coder

## Приоритет: high

## Ветка: feature/teams-redesign

## Контекст

Язык интерфейса всего приложения — русский. Кодер в рамках редизайна Teams добавил
украинские строки в двух файлах. Нужно заменить все украинские строки на русские.

## Конкретные изменения

### `apps/web/app/routes/crm/team/index.tsx`

Заменить строки (оставь логику нетронутой, меняй только текст):

| Украинский                                             | Русский                           |
| ------------------------------------------------------ | --------------------------------- |
| `Пошук за назвою…`                                     | `Поиск по названию…`              |
| `Всі ролі`                                             | `Все роли`                        |
| `Назва A→Z`                                            | `Название A→Z`                    |
| `Учасники ↓`                                           | `Участники ↓`                     |
| `Проекти ↓`                                            | `Проекты ↓`                       |
| `уч.`                                                  | `уч.` (оставить)                  |
| `проект` / `проекти` / `проектів`                      | `проект` / `проекта` / `проектов` |
| `Без HR`                                               | `Без HR` (оставить)               |
| `Нічого не знайдено`                                   | `Ничего не найдено`               |
| `Перейти до команди`                                   | `Перейти к команде`               |
| `Перейменувати`                                        | `Переименовать`                   |
| `Senior` / `HR` / `Junior` / `Accountant` в SelectItem | оставить как есть                 |
