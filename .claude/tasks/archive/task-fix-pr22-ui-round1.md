# task-fix-pr22-ui-round1

## Агент: coder

## Приоритет: high

## Ветка: fix/teams-ui-polish

## Контекст

User Testing PR #22 выявил несколько UX/UI проблем на страницах /crm/team и /crm/team/:id.
Все правки — в существующую ветку fix/teams-ui-polish, файлы:

- `apps/web/app/routes/crm/team/index.tsx`
- `apps/web/app/routes/crm/team/$teamId.tsx`

## Список правок

### Страница /crm/team (index.tsx)

1. **Аватарки сломаны** — у компонента Avatar пропал background/fallback. Проверь что `AvatarFallback` имеет явный фоновый цвет (например `bg-muted` или `bg-primary/10`), и что инициалы отображаются при отсутствии фото. Прогони через Playwright и убедись что аватарки видны.

2. **Telegram-кнопка выглядит сломано** — в карточке команды кнопка Telegram сейчас стоит неудачно. Переработай layout карточки команды:
   - Заголовок команды и Telegram-кнопка должны быть на одной строке: название слева, кнопка-иконка Telegram справа
   - Кнопка: иконка Send (уже импортирована), круглая, небольшая (`size="icon"` variant `ghost`), синяя (`text-blue-500 hover:text-blue-600 hover:bg-blue-500/10`). Показывать только если `team.telegram` заполнен.
   - Сделай её красивой и органично вписывающейся в карточку — не торчащей отдельным блоком.

### Страница /crm/team/:id ($teamId.tsx)

3. **Ссылки на контакты участника выглядят плохо** — email, phone, telegram сейчас не оформлены. Сделай:
   - Каждый контакт — отдельная строка с иконкой + текст, стилизованная как `text-sm text-muted-foreground hover:text-foreground transition-colors`
   - Email → `mailto:`, телефон → `tel:`, Telegram → `https://t.me/<username>` (убрать символ `@` если есть при формировании URL)
   - Telegram-ссылка должна открывать реальный Telegram профиль пользователя

4. **Клик по ссылке открывает профиль участника** — при клике на email/phone/telegram срабатывает navigate на `/crm/users/:id`. Добавь `e.stopPropagation()` на все `<a>` теги контактов, чтобы клик не всплывал на родительский `<Link>` карточки.

5. **Активные проекты — информация о джуне** — в секции активных проектов команды добавь под каждым проектом информацию о прикреплённом джуне:
   - Если джун есть: показать аватар + имя джуна (маленький, `text-sm`)
   - Если джуна нет: показать красный текст `"Джун не прикреплён"` (`text-destructive text-sm`)
   - Данные получить из `projects` (уже загружены в компоненте через `useQuery(['projects'])`). Для каждого активного проекта команды найти `project_members` с ролью JUNIOR и `leftAt === null`. В типе `ProjectDto` есть поле `members` с участниками.

6. **Telegram-кнопка команды стоит криво** — кнопка "Написать в Telegram" (канал команды) должна быть большой, красивой и естественно дополнять UI:
   - Разместить в шапке карточки команды (рядом с названием), не отдельным блоком
   - Стиль: `variant="outline"` с иконкой Send, синяя рамка (`border-blue-500/50 text-blue-400 hover:bg-blue-500/10 hover:border-blue-400`), достаточно крупная чтобы бросаться в глаза, но не ломать layout
   - Показывать только если `team.telegram` заполнен
