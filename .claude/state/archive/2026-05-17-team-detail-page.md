# Команда: детальная страница + обновлённый дизайн + RBAC джуна

## Ветка

`feature/team-detail-page`

## Что нужно сделать

### 1. Новый роут — детальная страница команды

Создать `apps/web/app/routes/crm/team/$teamId.tsx`.

**Отображает:**

- Название команды + дата создания
- Список участников командой: аватар, имя, роль (Badge), techStack
- Кнопки управления (добавить/удалить участника) — только для ADMIN и HR-owner

**RBAC фильтрация при отображении участников:**

- Если `viewer.role === 'JUNIOR'` → не показывать других участников с `role === 'JUNIOR'`
- Все остальные роли видят всех участников

### 2. Авто-редирект на `/crm/team`

В `apps/web/app/routes/crm/team.tsx` (существующий список):

- Если `user.role === 'SENIOR'` → `GET /api/teams` вернёт одну команду → redirect на `/crm/team/${teams[0].id}`
- Если `user.role === 'JUNIOR'` → `GET /api/teams` вернёт одну команду (с фильтрацией джунов на фронте) → redirect на `/crm/team/${teams[0].id}`
- ADMIN, HR, ACCOUNTANT — остаются на странице списка (без редиректа)

### 3. Обновить дизайн страницы-списка команд

Текущий дизайн — базовые карточки. Обновить:

- Сделать карточки команд более информативными: показывать краткий состав (аватары первых 4 участников + "+N"), название, количество активных проектов если доступно
- Добавить hover-эффект на карточку (она кликабельна → открывает `/crm/team/:id`)
- Кнопки "редактировать" и "удалить" оставить на карточке

### 4. API

`GET /api/teams/:id` — уже существует, возвращает `TeamDto` с `members[]`.

Проверить что endpoint доступен для SENIOR и JUNIOR (сейчас доступен только ADMIN и HR согласно RBAC). Если нет — добавить доступ.

**Фильтрация на сервере:** В `teams.service.ts`, в методе `findOne(id, user)`:

- Если `user.role === 'JUNIOR'` → отфильтровать из `team.members` всех с `role === 'JUNIOR'` перед возвратом

Это безопаснее чем фильтровать только на фронте.

## Файлы для изменения
